# Nikunj Agrawal — Personal Resume Website

A simple personal resume website built with HTML and CSS for the IIM Bangalore DBE web development assignment.

## Files
- `index.html` — page content and semantic structure
- `style.css` — colours, typography, spacing, cards, navigation and responsive layout

## Run locally
1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `resume-website`).
2. Upload `index.html`, `style.css` and this README.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish. Copy the live website URL.

## Before submitting
- Check every personal detail and update anything that is not accurate.
- Add your own email/contact link if you want one displayed.
- Add the real GitHub repository URL and live website URL to the assignment PDF.
- Open the published link in a private/incognito browser window to check that it works.
